
# Quick Deploy Reference Card

## 🚀 Fast Deployment Commands

### Development
```bash
npm start                    # Start dev server
npm run dev                  # Start with cache clear
npm run ios                  # iOS simulator
npm run android              # Android emulator
```

### Production
```bash
npm run deploy               # Clean + Build + Deploy (all platforms)
npm run build:all            # Build for iOS + Android
npm run build:android        # Build Android only
npm run build:ios            # Build iOS only
```

### Testing
```bash
npm run preview:android      # Quick Android test build
npm run preview:ios          # Quick iOS test build
```

### Troubleshooting
```bash
npm run reset                # Clear Metro cache
npm run clean                # Deep clean (removes native folders)
```

## ⚡ Speed Tips

1. **Use EAS Build** (not local builds)
2. **Keep Metro running** during development
3. **Clear cache** only when needed
4. **Use preview builds** for testing

## 📊 Expected Times

- npm install: ~14 seconds
- Dev server start: ~30 seconds
- Preview build: ~5-8 minutes
- Production build: ~5-10 minutes

## 🔧 Common Issues

### Metro Error
```bash
npm run reset
```

### Build Error
```bash
npm run clean && npm install
```

### Slow Build
Use EAS Build instead of local builds

## 📱 Platform Specific

### iOS
- Requires Mac for local builds
- Use EAS Build for cloud builds
- Test on simulator first

### Android
- Works on any platform
- Faster builds than iOS
- Test on emulator first

## 🎯 Deployment Checklist

- [ ] Update version in app.json
- [ ] Test on both platforms
- [ ] Run `npm run clean`
- [ ] Run `npm install`
- [ ] Build with EAS
- [ ] Test the build
- [ ] Submit to stores
