
# Fast Deployment Guide for Anatomy Trainer

## Quick Start Commands

### Development
```bash
# Start development server (fastest)
npm start

# Start with cache clear (if you have issues)
npm run dev

# Platform specific
npm run ios
npm run android
npm run web
```

### Production Builds

#### Using EAS Build (Recommended - Fastest)
```bash
# Install EAS CLI globally (one time)
npm install -g eas-cli

# Login to Expo
eas login

# Build for Android
eas build --platform android --profile production

# Build for iOS
eas build --platform ios --profile production

# Build for both
eas build --platform all --profile production
```

#### Local Builds (Slower)
```bash
# Android
npm run prebuild
cd android && ./gradlew assembleRelease

# iOS
npm run prebuild
cd ios && xcodebuild -workspace *.xcworkspace -scheme * archive
```

## Optimization Tips

### 1. Clear Cache Before Building
```bash
npm run clean
npm install
```

### 2. Use EAS Build Profiles
- **development**: Fast builds with debugging
- **preview**: Internal testing builds
- **production**: Optimized production builds

### 3. Reduce Bundle Size
- Remove unused dependencies
- Use code splitting
- Optimize images before adding to assets

### 4. Speed Up Metro Bundler
- Keep Metro running during development
- Use `--reset-cache` only when needed
- Avoid importing large libraries in entry files

## Common Issues & Solutions

### Metro Bundler Errors
```bash
# Clear all caches
npm run clean
npm install
npm start
```

### Build Failures
```bash
# Reset native projects
npm run prebuild

# Or clean everything
rm -rf node_modules
npm install
```

### Slow Builds
- Use EAS Build instead of local builds
- Upgrade to paid EAS plan for faster build machines
- Enable caching in eas.json (already configured)

## Build Time Estimates

- **EAS Build (Production)**: 5-15 minutes
- **EAS Build (Preview)**: 3-10 minutes
- **Local Build**: 15-30 minutes
- **Development Start**: 30-60 seconds

## Best Practices

1. **Always use EAS Build for production**
2. **Test with preview builds before production**
3. **Keep dependencies up to date**
4. **Use TypeScript for better error catching**
5. **Enable source maps for debugging**
6. **Monitor bundle size regularly**
